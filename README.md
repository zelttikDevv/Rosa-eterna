# Rosa Eterna

Una rosa eterna bajo cristal: pétalos, chispas y un mensaje que florece para siempre.

Página estática sin dependencias (HTML + CSS + JS). Ábrela directo en el navegador o sírvela con cualquier servidor estático.

> “Prometí amarte cada día, hasta que cayera el último pétalo de este tulipán eterno... La flor sigue aquí, cuidada y eterna. Y aunque hoy no estemos juntos, mi amor por ti también sigue aquí: siempre tendrás un lugar especial en mi corazón.”

*Eventualmente todo lo que es para ti termina encontrándote.*
